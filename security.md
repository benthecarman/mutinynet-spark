# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to **benthecarman@live.com**.

Include a description of the issue, the steps required to reproduce it, and
the potential impact. Please do not open a public GitHub issue for
security vulnerabilities.

We aim to acknowledge reports within 72 hours and will keep you informed as
a fix is developed.
